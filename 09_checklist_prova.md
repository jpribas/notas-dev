# Checklist para a prova

## Antes de começar (5 min)
- [ ] Ler o enunciado **todo**.
- [ ] Ligar XAMPP (Apache + MySQL) e abrir o phpMyAdmin.
- [ ] Ver os nomes que o enunciado exige (BD, ZIPs).
- [ ] Planear o tempo: M1 ~1h30, M2 ~1h30, M3 o resto (é o que mais pontos vale se funcionar).

## M1
- [ ] Tabelas e colunas escritas (modelo em texto).
- [ ] ER em Chen exportado.
- [ ] `CREATE DATABASE` com o **nome exato**.
- [ ] 5 `CREATE TABLE`, pela ordem certa.
- [ ] Dados mínimos (confirma as quantidades).
- [ ] Todas as consultas, corridas e confirmadas.
- [ ] Ficheiro `.sql` único e testado do zero.
- [ ] ZIP com o nome certo.

## M2
- [ ] Casos de uso.
- [ ] Fluxograma.
- [ ] Wireframes de todos os ecrãs.
- [ ] ZIP com o nome certo.

## M3 (por esta ordem)
- [ ] Servidor liga e liga à BD.
- [ ] **Uma** tabela completa (listar/criar/editar/apagar) a funcionar, front e back.
- [ ] Copiar para as restantes tabelas.
- [ ] Validações do enunciado, uma a uma.
- [ ] Regras de negócio (vagas, estados).
- [ ] Menu com links.
- [ ] Mensagens de sucesso/erro e `confirm()` ao apagar.
- [ ] README com como correr (`npm install`, `.env`, `npm start`).
- [ ] **Não** incluir `node_modules` no ZIP.
- [ ] Testar do zero: apagar `node_modules`, `npm install`, `npm start`.

## Regras de sobrevivência
- Funciona > bonito.
- Guarda e testa de 15 em 15 minutos.
- Se emperrares mais de 10 min, passa à seguinte e volta depois.
- Lê a mensagem de erro (número e texto): diz-te onde está.
- Respira. Já fizeste o RiaTour e o Palheiro.
